## Introduction

The current project configuration enforces a consistent coding style. The project uses TSLint to provide warnings for inconsistent source code.

## TSLint

Learn more about [TSLint](https://github.com/palantir/tslint). If you use Visual Studio Code, [vscode-tslint](https://github.com/Microsoft/vscode-tslint) integration can improve your coding experience.

TypeScript linting is part of the build process. Each time code is rebuilt, style errors and warnings are reported.

See the current coding style in [`tslint.json`](https://github.com/alan-null/sc_ext/blob/master/tslint.json). Each configuration node is explained in the [TSLint rules documentation](http://palantir.github.io/tslint/rules/).
