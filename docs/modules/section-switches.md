## Overview

Easily open or close all item sections with one click.

[![Section Switches demo](https://alan-null.github.io/blog/images/posts/sc-ext-1.0.0/section_switches.gif)](https://alan-null.github.io/blog/images/posts/sc-ext-1.0.0/section_switches.gif)

## Launcher commands

**Section Switches** provides these Launcher commands:

| Name | Description |
| :--- | :--- |
| Open sections | Open all closed sections |
| Close sections | Close all opened sections |

Read more about the [Launcher module]({{ site.baseurl }}{% link modules/launcher/index.md %}).
