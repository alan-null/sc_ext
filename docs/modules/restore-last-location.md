## Overview

Command that restores the last opened item in Content Editor.

Forget that feeling when you come back from your lunch break and the opened tab with **CE** has changed to the login screen.

[![Restore Last Location demo](https://alan-null.github.io/blog/images/posts/sc-ext-2.0.0/restore_last_opened_item.gif)](https://alan-null.github.io/blog/images/posts/sc-ext-2.0.0/restore_last_opened_item.gif)

## Launcher commands

**Restore Last Location** provides this Launcher command:

| Name | Description |
| :--- | :--- |
| Restore Last Opened Item | Restores the last opened item in Content Editor |
